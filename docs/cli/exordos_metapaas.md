
# exordos_metapaas

metapaas group in the Exordos installation

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos metapaas [OPTIONS] COMMAND [ARGS]...                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                                           
```

## Options

* `metapaas_endpoint`:
    * Type: text
    * Default: `none`
    * Usage: `--metapaas-endpoint`

  Exordos metapaas API endpoint, defaults to the metapaas element behind the endpoint

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
