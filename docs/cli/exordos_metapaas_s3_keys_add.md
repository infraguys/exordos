
# exordos_metapaas_s3_keys_add

Add a new access key

## Usage

```console
                                                                                                                                                                                                                                                                                                           
 Usage: exordos metapaas s3 keys add [OPTIONS]                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                           
```

## Options

* `uuid`:
    * Type: uuid
    * Default: `none`
    * Usage: `-u
--uuid`

  UUID of the access key

* `project_id` (REQUIRED):
    * Type: uuid
    * Default: `sentinel.unset`
    * Usage: `-p
--project-id`

  UUID of the project in which to create the access key

* `instance_uuid` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `-i
--instance-uuid`

  UUID of the instance to create the access key in

* `user_uuid` (REQUIRED):
    * Type: text
    * Default: `sentinel.unset`
    * Usage: `--user-uuid`

  UUID of the user to create the access key for

* `secret_key`:
    * Type: text
    * Default: `none`
    * Usage: `--secret-key`

  Secret key, generated by the API when omitted

* `help`:
    * Type: boolean
    * Default: `false`
    * Usage: `--help`

  Show this message and exit.
